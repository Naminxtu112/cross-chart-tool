十字図作成ツール
==================

このフォルダ内の4ファイルを、同じ階層のままGitHubのリポジトリへ登録してください。

必要なファイル
--------------
1. index.html
   Webページ本体です。

2. style.css
   画面の色、余白、ボタン、レスポンシブ表示などを設定します。

3. axis-sets.js
   図番号と4方向の軸名を登録するファイルです。
   通常は、このファイルだけ編集すれば軸セットを追加・修正できます。

4. app.js
   ランダム表示、番号指定、文字配置、マーカー、色、移動、PNG保存を処理します。

軸セットの編集方法
------------------
axis-sets.jsをテキストエディタで開きます。

次の形式で1セットが登録されています。

  {
    id: 1,
    name: "セット1",
    top: "理論的",
    bottom: "実践的",
    left: "個人的",
    right: "社会的"
  }

意味：
- id: 図番号。重複しない正の整数にします。
- name: 管理用の名称です。
- top: 上方向の軸名です。
- bottom: 下方向の軸名です。
- left: 左方向の軸名です。
- right: 右方向の軸名です。

新しいセットを追加するときは、直前の項目の末尾にカンマを付け、同じ形式で追記します。

使用方法
--------
1. Webページを開きます。
2. 図番号を入力するか、空欄のまま「十字図を開く」を押します。
3. 図中の文字を置きたい位置をクリックします。
4. 文字を入力します。
5. 必要なときだけ、マーカー形状や色を変更します。
6. 「項目を追加」を押します。Enterキーでも追加できます。
7. 配置済みの文字をクリックすると編集できます。
8. 配置済みの文字はドラッグで移動できます。
9. 「画像として保存」を押すとPNG画像が端末へ保存されます。

注意
----
- デフォルトはマーカーなしで、文字だけが配置されます。
- 図を切り替えると、その時点の配置内容は消去されます。
- 作成内容はサーバーへ送信されません。使用者のブラウザ内で処理されます。
- 画像保存に対応していない端末では、スクリーンショットを案内するメッセージが表示されます。
